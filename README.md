# ResourceScript

Консольная утилита для массового изменения файла ресурсов UNIPOS (`unipos.xml`): 
вставляет заданный GUI-элемент в диалоги выбранных конфигураций платёжных терминалов.
Написана на C++/Qt в 2017 году для автоматизации ручной правки ресурсов.

## Вход и выход

Запуск: `ResourceScript <unipos.xml> <фрагмент.xml>`

- **Первый аргумент** — исходный файл ресурсов `unipos.xml` (в репозитории, ~5,5 МБ:
  модуль `unipos` «Приложение по обслуживанию карт МПС», секции Display, Debug, Dialogs, Print, ExtendedDevice; в секции Dialogs — 15 конфигураций моделей терминалов).
- **Второй аргумент** — XML-фрагмент с вставляемым элементом (пример — `caption.xml`).
- **Результат** — изменённая копия ресурсов в файле `unipos-modified.xml` в текущем каталоге; имя выходного файла жёстко задано в коде (UTF-8 с BOM).
- Без аргументов программа печатает описание; опция `-c/--command` объявлена, но не используется.

## Логика работы (addertores.cpp)

1. Разбирается файл-фрагмент (`QDomDocument`).
2. В `unipos.xml` рекурсивно ищется `Section Name="Dialogs"`, внутри неё — `Configurations`.
3. Обрабатываются конфигурации из зашитого в коде списка (графический режим): `240x320_VerixV_IG`, `320x240_Pax_IG`, `320x240_VerixV_IG`, `240x320_Pax_IG`, `800x480_Pax_IG`, `320x240_Pax_IG_D210E`.
4. Спуск по цепочке `Languages → Language → Messages`; в каждом диалоге (`xsi:type="Dialog"`)
   находится `DialogControls`, куда добавляется копия элемента из фрагмента (`cloneNode`).
5. Документ сохраняется в `unipos-modified.xml`.

## Технологии

- C++11, Qt 5 (консольное приложение: `QT -= gui`, `QT += xml`).
- XML: DOM-модель `QDomDocument`; вывод через `QTextStream` (UTF-8 + BOM).
- CLI: `QCommandLineParser`; сообщения на русском, консольный вывод в CP866.

## Структура

- `ResourceScript.pro` — проект qmake;
- `main.cpp` — разбор аргументов командной строки;
- `addertores.cpp`, `addertores.h` — основная логика (класс `AdderToRes`);
- `unipos.xml` — обрабатываемый файл ресурсов UNIPOS;
- `caption.xml` — пример вставляемого фрагмента (`GuiControl xsi:type="GraphicCaption"`).

## Сборка

```
qmake ResourceScript.pro
make
```
